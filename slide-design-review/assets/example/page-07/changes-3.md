# 変更 3: page 7

## 直した問題
- Priority 1（[M1] [m2]）: タイトル（32px・500）がカード見出し「第n段階」（44px・太字）より小さく、主張行（28px・700）より細い。カード説明文（32px）とも同じ大きさで、タイトルが見出しとして働かない。近いサイズ（28 / 32 / 38〜44）が混ざっている

## 原因
- style.css の `.slidev-layout .md-title` は全ページ共通で `--md-size-title`（32px）・太さ 500。`.md-conclusion` は `--md-size-conclusion`（28px）・太さ 700。結論のほうが太いという関係は、デッキ全体の既定のまま
- このページは変更1・2で Step size="lg" の中の文字を大きくした（段階名 `--md-size-figure-label` 44px、説明 `--md-size-figure-desc` 32px、「約」「項目」`--md-size-figure-unit` 40px）。ヘッダーは既定の 32px / 28px のままだったため、図の中の文字がヘッダーを上回った
- ヘッダーの大きさはページごとに変える手段が layout に無く、slides.md には文字サイズを書けない

## 意図した見た目の変化
- タイトル「自動化は一度に全部やらず、3段階で広げる」が 54px・太字になる（21字で約1130px、1行のまま）。画面で数字（130px）の次に強い要素になり、カード見出し（40px）より明らかに大きい（約1.35倍）
- 主張行は 32px・標準の太さ・本文（#222）より薄いグレー（#555）になり、タイトルの下の一段下の行として読める。太さの逆転（主張行のほうが太い）は無くなる
- タイトルと主張行の字面の間は約20px（間隔 4px ＋ タイトルの行の上下余白 約8px ＋ 主張行の行の上下余白 約8px）
- カード見出し「第n段階」は 44px → 40px
- 段差は、数字 130px ＞ タイトル 54px ＞ カード見出し・「約」「項目」40px ＞ 主張行・説明文 32px ＞ フッター 18px の5段になる（使うサイズが 18 / 32 / 40 / 54 / 130 の5種類。28px と 44px が無くなり、近いサイズが並ばない）
- ヘッダーの高さは約14px増える（タイトル +22px、主張行 +6px、間隔 −14px）。カード列は本文領域の上下中央に置かれているので、約7px下へずれるだけ
- 良い点の維持: カードの幅・高さ・間隔・矢印、カード内の「見出し → 数字 → 説明」の順と数字の大きさ、「約」「項目」のベースライン揃え、第1段階だけの太字と濃い枠、白・黒・グレーだけの配色は変えていない。追加したグレー（#555）も無彩色

## 規約との関係
- slides.md に文字サイズ・色・`<style>` を書けないため、frontmatter には `header: lg` という型の名前だけを書き、サイズと色は style.css の変数、切り替えは layouts/md-wide.vue で行った（Step の `size="lg"` と同じ方式）
- 主張行の「本文色より少し薄いグレー」は、既存の変数に文字用のグレーが無い（`--md-line` #b5b9bd は線用で、文字には薄すぎる）ため `--md-fg-sub: #555555` を足した。白地とのコントラストは約7.5:1
- 改善案の「カード見出し 約36〜40px」は、「約」「項目」（40px）と近い別サイズを作らないよう 40px にそろえた
- 最小文字サイズ 18px を下回る文字はない

## 採らなかった案
- `--md-size-title` と `.md-title` / `.md-conclusion` の既定を全ページで変える: 本文 22px の md-standard のページまでタイトルが 54px になり、長いタイトル（最終ページの「第1段階の完了を来月末とし、…目標にする」約43字）が2行に折れて図や本文が押し下がる。変わるページが9ページに広がるため、範囲の小さい `header: lg` にした
- md-wide の全ページで強くする（frontmatter 無しで md-wide.vue の scoped style で変える）: 比較表のページ（本文 22px 程度）まで変わる。今回の問題は大きな文字の図とヘッダーの釣り合いなので、図に合わせて選べる指定にした
- カード見出しと説明文を 32px 未満に下げて、タイトル 32px のまま差を作る: 変更2で箱を埋めるために大きくした中身がまた小さくなり、箱の空洞が戻る。主張行のほうが太い問題も残る
- 主張行を 500 にする: グレーにしたうえで 500 だとタイトル（700）との太さの差が小さくなる。改善案の「標準か中くらい」のうち標準の 400 にした

## 気づいたが直していないこと
- Priority 2（[M2]）: 外周の余白（48px）がカード間（約130px）より狭い、ヘッダーとカード列の間が約240px空く問題は今回の対象外。今回ヘッダーが約14px高くなるので、間は約230pxになる見込み
- Priority 3（[m1]）: 矢印が細く弱い問題は今回の対象外
- 主張行のほうがタイトルより太いという関係は、ほかのページ（md-standard の全ページと、もう1つの md-wide のページ）にも残っている

## 提案（この役では実施しないこと）
- タイトルと主張行の段差（タイトル＞主張行、主張行は標準の太さ）をデッキ全体にそろえるなら、`.md-title` と `.md-conclusion` の既定を変える。その場合、長いタイトルの折り返しとページごとの本文の押し下げを確認する必要がある。7ページ目だけタイトルが 54px になるので、前後のページと並べて見たときのタイトルの大きさの差も、デッキ全体の判断として人が見る必要がある
