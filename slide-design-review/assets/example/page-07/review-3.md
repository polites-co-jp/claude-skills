## Overall assessment

白地に3枚のカードを等間隔で並べた、落ち着いた構成のページ。最初に目が行くのは第1段階の太い「50」で、次に「150」「200」へ横に流れる。ページのタイトルと主張を読むのは最後になる。素人っぽく見える一番の原因はヘッダーが弱いこと。タイトル（約32px・標準の太さ）はカード見出しの「第n段階」（約44px・太字）より小さく、下の主張行（約28px・太字）より細い。そのため、左上に小さな注記が置かれているように見え、ページの言いたいことの入口になっていない。

## Critical issues

なし

## Major issues

- [M1] タイトルが、カード見出し（約44px）やカード説明文（約32px）と比べて同じか小さい。しかも下の主張行のほうが太く、タイトル→主張→本文の順に強さが下がっていない。（左上のヘッダー2行）
- [M2] 余白が狭い順に並んでいない。外周の余白（左右・上 約48px）がカード間の間隔（約130px）より狭く、カード列が左右の端に張り付いて見える。ヘッダーとカード列の間は約240px空いた帯になっていて、ヘッダーが本体から離れて浮いて見える。（画面の左右端、ヘッダーとカード列の間）

## Minor issues

- [m1] 段階の間の矢印「→」が細い文字の矢印で、太い数字やカードの枠と比べて線が弱く、キーボードで打った記号のように見える。（カード間の2本の矢印）
- [m2] 1ページで使う文字サイズが約7種類ある（約28 / 32 / 38 / 44 / 120px ほか、フッター約18px）。タイトル（約32px）とカード説明文（約32px）、主張行（約28px）のように近いサイズが混ざり、サイズの差が意図したものに見えない。（ヘッダーとカード内）

## Priority 1

- 対応する指摘: [M1], [m2]
- 観点: Visual hierarchy
- 問題: 左上のタイトル「自動化は一度に全部やらず、3段階で広げる」は約32px・標準の太さ。すぐ下の主張行は約28px・太字。カード見出し「第1段階」は約44px・太字で、タイトルより大きい。カード説明文も約32pxで、タイトルと同じ大きさ。
- なぜ問題か: ページで一番大きい文字でも一番太い文字でもないため、タイトルが見出しとして働かない。主張行のほうが太いので、タイトルと主張のどちらが上位なのかも読み取れない。数字を見終えたあとに戻る場所が無く、「3段階で広げる」というページの枠組みが最後まで入ってこない。
- 改善案: タイトルを約52〜56px・太字（またはセミボールド）にする。主張行は約30〜32pxに上げ、太さを標準か中くらいに落とし、本文色より少し薄いグレーにする。タイトルと主張行の間は約16〜20pxにする。カード見出し「第n段階」は約36〜40pxに下げ、タイトルより確実に小さくする。こうすると、タイトル（約54px）＞カード見出し（約38px）＞主張行・説明文（約30〜32px）の段差ができる。
- 直ったと分かる見え方: ヘッダーを見たとき、タイトルが画面で2番目に強い要素（数字の次）になり、カード見出しより明らかに大きく見える。主張行はタイトルに従う1段下の行として読める。

## Priority 2

- 対応する指摘: [M2]
- 観点: Whitespace
- 問題: カード列の左右が画面端から約48pxしかなく、カード間の約130pxより狭い。ヘッダー下端（y≈140）からカード上端（y≈380）までは約240px空いている。
- なぜ問題か: 外周の余白が要素間の間隔より狭いので、カード列が画面の幅に合わせて引き伸ばされたように見え、窮屈に感じる。一方でヘッダーとカード列の間は大きく空いているため、ヘッダーとカードが同じページの一続きの話に見えず、配置がまだ決まっていない印象を与える。
- 改善案: 画面の左右の余白を約96〜120pxに広げ、タイトル・主張行・カード列・フッターの左端をその線で揃える。カードは幅を詰めて（1枚あたり約480px程度）、カード間の間隔は約90〜100pxにし、外周の余白より狭くする。カード列を約60〜80px上へ動かして、ヘッダーとの間を約140〜160pxにする。カードの高さを約460〜480pxに少し伸ばし、下の空きも同じ程度に揃える。
- 直ったと分かる見え方: 外周の余白 ≧ ヘッダーとカード列の間 ＞ カード間の間隔、の順に見える。カード列が画面の端から離れて、ヘッダーのすぐ下にまとまった一つの塊として見える。

## Priority 3

- 対応する指摘: [m1]
- 観点: Visual semantics
- 問題: カード間の矢印が細い文字の「→」（長さ約60px、線の太さ約2px）で、太い数字や枠と比べて弱い。
- なぜ問題か: 段階が順に進むことを示す唯一の要素なのに、線の太さも長さも周りの要素より弱く、流れを示す図として目に入らない。
- 改善案: 矢印を文字ではなく線で描き、線の太さ約3px、長さ約70〜80pxにする。色は第1段階のカードの枠と同じ濃いグレーにする。上下位置は今のまま、数字の中心の高さ（y≈588）に合わせる。
- 直ったと分かる見え方: 目を細めたときに、3枚のカードが矢印で左から右へつながった一続きの流れとして見える。

## Positive aspects

- 3枚のカードは幅・高さ・上端・カード間の間隔がきちんと揃っている。左右の2か所の矢印も同じ位置関係で置かれていて、横並びの構造が崩れていない。
- カードの中は「見出し → 大きな数字 → 説明」の3段になっていて、数字（約120px）が抜きん出て大きい。どのカードも読む順に迷わない。
- 「約」と「項目」を数字より大きく小さくし、数字のベースラインに揃えている。数字が主役で単位が脇役だとはっきり分かる。
- 第1段階だけを太字と濃い枠で強調し、第2・第3段階は標準の太さと薄い枠にしている。強調が1か所に絞られていて、主張行の「第1段階から始める」と見た目が一致している。
- 色は黒・グレー・白だけで、影・グラデーション・アイコンといった装飾が無い。静かで整った印象になっている。
