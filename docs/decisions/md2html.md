# md2html 設計裁定記録

`md2html` の設計で決めた判断を、決めた順に記録する。
元の依頼は、作者が会話で示した要件（2026-10-07）。
- docs 以下の md（docs/html を除く全フォルダ）を html にし、docs/html 以下に揃える
- リンクは html になっても維持する
- html は LLM ではなく node プログラムで生成し、md の作成・編集時に hook で実行するだけにする

共通の公開仕様は [common.md](common.md)。

> **状態**: 2026-10-07、grill-me の対話（AskUserQuestion）で W1〜W12 を作者が選んだ。W13 は質問せずに既定として決め、同じ対話の中で作者に示した。
> 2026-10-08、作者の指示で実装した。実装の中で決めた細部は W14。

## 裁定

### W1. hook は Claude の編集だけを拾う（2026-10-07）

- `PostToolUse`（Write / Edit / MultiEdit）で、編集された md を1つ変換する。
- 手動編集や git pull は拾わない。取りこぼしは全件変換のコマンド（`--all`）で補う。
- 退けた案: ファイル監視や git hook を足して手動編集も拾う案／SessionStart で差分を同期する案。

### W2. hook は setup コマンドで対象プロジェクトに入れる（2026-10-07）

- スキル同梱の setup が、対象プロジェクトの `.claude/settings.json` に hook を冪等に追記する。
- 退けた案: 手順書だけ用意して人が追記する案。
- W8 で、hook が参照する変換器の置き場所を変えた（スキルの絶対パス → 対象リポジトリ内のコピー）。

### W3. md へのリンクは .html に書き換え、アンカーは残す（2026-10-07）

- 相対リンク `*.md` を `*.html` にし、`#アンカー` はそのまま残す。外部 URL は触らない。
- リンク先の md が無ければ、警告を出してリンクは元のまま残す（通知の仕方は W12）。
- 退けた案: リンクを一切書き換えない案（要件「リンクを維持」を満たさない）。

### W4. 変換エンジンは markdown-it（2026-10-07）

- リンクの書き換えは、出来上がった HTML を正規表現でいじるのではなく、トークン単位で行う。
- 退けた案: marked／依存ゼロの自前実装。
- 配り方: markdown-it と、その依存（W11 の highlight.js も含む）を esbuild で1ファイルにまとめ、ライセンス表記と一緒にスキルに同梱する。npm install は要らず、hook は node だけで動く。
  - 退けた案: setup がスキルのフォルダで npm install する案／対象プロジェクトの devDependencies に入れる案。

### W5. 全ページに共通のサイドバーナビを付け、index.html も生成する（2026-10-07）

- 本文には共通の CSS を当てる。
- 退けた案: 最小テンプレート（共通 CSS＋ページ内目次）／装飾なしの素の HTML。

### W6. ナビは nav.js に分け、編集時は「そのページ・nav.js・index.html」だけを書く（2026-10-07）

- 各 html は `<script src>` で nav.js を読む。file:// でも動く。本文とリンクは JS が無くても読める。
- 退けた案: 毎回すべての html を再生成し、ナビを埋め込む案／内容が変わったファイルだけを書く全再生成。

### W7. 孤立した html は hook が走るたびに掃除する（2026-10-07）

- nav.js を作るときに全 md を走査するので、ついでに対応する md の無い html を消す。
- 消すのは `<meta name="generator">` の印が付いた生成物だけで、人が置いたファイルは残す。
- 退けた案: `--all` を実行したときだけ掃除する案／消さない案。

### W8. 生成した html はコミットする。変換器は対象リポジトリへコピーする（2026-10-07）

- docs/html はコミットする。md と html のずれは `--check` で検出する。`--check` は、ずれがあれば失敗するコマンド。
- `--check` を成り立たせるため、出力には生成日時のように実行ごとに変わる値を入れない。
- setup は変換器を `.claude/md2html/` へコピーする。hook も `--check` も相対パスでそれを使う。設定に絶対パスは入らず、チームや別の端末でもそのまま動く。
- スキルを更新したら setup をもう一度実行して上書きする。コピーした変換器の版をファイルに記録し、スキルより古ければ hook が警告する。
- 退けた案: hook がスキルを絶対パスで参照する案（W2 の当初の形。リポジトリを clone した他人の環境では動かない）。

### W9. 入出力のパスは既定 docs → docs/html。config.json で変えられる（2026-10-07）

- `.claude/md2html/config.json` に `srcDir` と `outDir` を持たせ、setup の引数でも指定できる。設定の項目はこの2つに限る。
- outDir が srcDir の中にあるときは、走査の対象から自動で外す。
- 退けた案: docs → docs/html に固定する案。

### W10. GitHub を前提にした機能は作らない（2026-10-07）

- setup は CI の workflow を作らない。`--check` は CI に組み込まず、手で走らせるコマンドとして提供する。
- 作者の回答は「github 前提の機能は不要」。

### W11. GFM に加え、frontmatter・タスクリスト・Mermaid・シンタックスハイライトに対応する（2026-10-07）

- frontmatter は本文に出さない。`title` は `<title>` とナビの表示名に使う。title が無ければ最初の h1 を使い、h1 も無ければファイル名を使う。
- Mermaid は、図を含むページにだけ、版を固定した jsDelivr の script タグを入れる。オフラインでは図にならず、図のソースがコードブロックとして見える。
  - 退けた案: mermaid.min.js（約3MB）を docs/html へコピーする案／生成時に SVG にする案（ヘッドレスブラウザが要り、hook が数秒かかる）。
- シンタックスハイライトは生成時に highlight.js を当てる。対応するのは common（主要な約35言語）までで、それ以外の言語は色を付けずに出す（既定。対話の中で作者に示した）。

### W12. 切れリンクは Claude に伝え、変換は最後まで行う（2026-10-07）

- html は必ず出力する。切れリンクがあれば exit 2 で終わり、stderr に `docs/a.md:12 のリンク先 b.md が無い` のように場所を出して、Claude がその場で直せるようにする。変換器の例外も同じ方法で伝える。
- 退けた案: 例外だけを伝え、切れリンクは黙って通す案／何も伝えない案。

### W13. md 以外への相対リンクは元ファイルを指すパスに振り直す。ほかの既定（2026-10-07）

- 画像や PDF など md 以外へのリンクは、html の位置から元ファイルへの相対パスに書き換える（例：`docs/guide/img/x.png` は、`docs/html/guide/a.html` から見て `../../guide/img/x.png`）。ファイルはコピーしない。
  - 代償: docs/html だけを切り出して配ると、これらのリンクは切れる。
  - 退けた案: docs/html の下へコピーする案／そのまま残す案。
- 以下は質問せずに既定として決め、対話の中で作者に示した。
  - srcDir の外にある md へのリンク（例：`../README.md`）は、元の md を指すパスに振り直す。
  - `docs/index.md` があれば、それを `index.html` にする。無ければファイル一覧のページを生成する。
  - 見出しのアンカーは GitHub と同じ規則の ID にする。
  - 出力の改行は LF にする。
  - hook は `.claude/settings.json` に入れる。srcDir の外の md や、outDir の中の編集は無視する。
  - スキルを呼ぶと、setup・全件変換・結果の報告まで行う。もう一度呼ぶと変換器の更新になる。

### W14. 実装の中で決めた細部（2026-10-08）

- 置き場所: Skill は `md2html/` に置く。中身は次の4つ
  - `runtime/`（setup がプロジェクトへそのままコピーする一式）
  - `scripts/setup.mjs`
  - `tools/`（同梱のライブラリを作り直すためのもの。利用者は使わない）
  - `tests/convert.mjs`
- 共通ファイル: nav.js と style.css は出力先の `_md2html/` に置く。docs の中に同じ名前のフォルダがあると衝突するが、まれなので対策しない。
- 版: `runtime/version.json` に持つ（初版は 1.0.0）。
  - hook が探す導入済みの Skill は3か所。プロジェクトの `.claude/skills/md2html`、`~/.claude/skills/md2html`、`~/.agents/skills/md2html`
  - そこに新しい版があれば知らせる。知らせるのはセッションごとに1回（W8 の警告の具体化）
- Mermaid: 版を 12.1.0 に固定する。配色は閲覧者の OS のダークモードに合わせる。
- hook の登録: harness と同じ実行形式（`node` と `args`、`${CLAUDE_PROJECT_DIR}`）にする。timeout は30秒。
- 終了コード:
  - setup: 書く前に検査で止めたら 1。導入はしたが切れたリンクがあれば 2
  - `--all`: 切れたリンクがあれば 2（setup の 2 はここから来る）
  - `--check`: ずれがあれば 1。切れたリンクは警告に出すだけで、終了コードには影響しない
- ずれの判定: 改行の CRLF と LF の違いは、ずれに数えない。git の autocrlf で取り出し直しただけの html が、ずれと判定されないようにするため。
- `<html lang>`: 本文に日本語の文字があれば `ja`、無ければ `en` にする（C1 の「成果物は利用者の言語」に合わせる）。
- 確認済み（2026-10-08、Node.js 24、Windows 11）:
  - `tests/convert.mjs` の全場面が通った
  - 一時プロジェクトで Claude Code（`claude -p`）に md を Edit させると、hook が発火して html が更新された
  - Playwright でライト・ダーク・幅 390px の画面を撮って、見た目を確かめた
