# 最終チェックリスト

Step 7 で全スライドを点検する。違反を見つけたら該当する Step に戻って直す。

## 内容

- [ ] 入力の箇条書きがすべてどこかに反映されている（画面か発表者ノート）。落とした情報は計画の「本編に入れなかった情報」に理由と一緒に書いてある
- [ ] 入力にない事実・主張・数値を足していない。補足したい箇所は「確認が必要な事項」に回してある
- [ ] 最新情報（製品の機能・価格・対応状況）に触れる箇所に、発表前の確認が要ると明示してある
- [ ] セクションの順は入力どおり（並べ替えたなら承認済み）
- [ ] 分割・統合は承認されたものだけ

## メッセージ

- [ ] 各説明スライドに `conclusion` が1つある。結論未定のスライドが残っていない
- [ ] 結論行がタイトルの言い換えになっていない
- [ ] 結論行だけを順に読んで、飛躍・重複がない（あるなら報告に書いてある）
- [ ] 結論と説明・図が矛盾していない

## 文章

- [ ] 本文の要素は3つ前後、1要素は全角20字程度（配布用なら5つ・30字程度）
- [ ] 体言止め・短いフレーズ。句点で終わる文が並んでいない
- [ ] 否定・条件・比較・因果は、体言止めで意味が変わっていない
- [ ] 数値・固有名詞・定義・手順・比較の軸・URL・引用は画面に残っている
- [ ] 同じリストの要素の文末が揃っている
- [ ] 「勝者」「最適」「最強」などの評価語、無条件の礼賛がない

## 図解

- [ ] プロセス・分岐・階層・比較・構成は図になっている
- [ ] 図を置くために作った内容がない
- [ ] 同じ概念は同じ部品・同じ並びで描き、強調（`highlight`／`overlay`）だけが変わっている
- [ ] 1スライドに図は1つ
- [ ] `Comparison` の `highlight` が勝敗の意味になっていない
- [ ] Step・Branch・Architecture の外に矢印を足していない

## デザイン

- [ ] `slides.md` に `<style>`、色、文字サイズ、UnoCSS のクラスを書いていない
- [ ] レイアウトは `md-cover`／`md-toc`／`md-section`／`md-standard`／`md-wide` だけ
- [ ] `EmphasisBox` は1スライドに1つまで
- [ ] `figureWidth` は 33%〜55% の範囲
- [ ] headmatter が [components.md](components.md) の雛形どおり（`canvasWidth: 1920`、フォント、`colorSchema: light`）
- [ ] 画像を生成・埋め込みしていない（イラストは候補として報告）

## プレゼン全体

- [ ] 表紙がある。`##` が2つ以上なら区切りがある。`##` が3つ以上なら目次がある
- [ ] 結びは入力にあるときだけ
- [ ] 文章だけのスライドが続いていない（続くなら、図にできる内容が無いことを確かめた）
- [ ] 各スライドに発表者ノートと想定時間がある
- [ ] 持ち時間が分かっていれば、想定時間の合計を照合した
- [ ] `slide-plan.md` が承認した内容と一致している

## ビルド

- [ ] `npx slidev build` が通る
- [ ] `dist/` を消した
- [ ] 報告に、はみ出し・文字の重なりは実機で確認してほしいと書いた
