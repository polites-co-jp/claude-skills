# 最終チェックリスト

Step 7 で全スライドを点検する。違反を見つけたら該当する Step に戻って直す。

## 内容

- [ ] 入力の箇条書きがすべてどこかに反映されている（画面・発表者ノート・計画の「本編に入れなかった情報」）
- [ ] 入力にない事実・主張・数値を足していない。補足したい箇所は「確認が必要な事項」に回してある
- [ ] 最新情報（製品の機能・価格・対応状況）に触れる箇所に、発表前の確認が要るとノートに書いてある
- [ ] セクションの順は入力どおり（並べ替えたなら承認済み）
- [ ] 分割・統合・削除は承認されたものだけ

## タイトルと結論

- [ ] タイトルは話題名（名詞句、全角15字程度まで）。主張の文になっていない
- [ ] 段階を追うスライド群に通し番号がある（該当するときだけ）
- [ ] 各説明スライドに `conclusion` が1つある。結論未定のスライドが残っていない
- [ ] 結論は `|-` で文節ごとに改行され、1行12字程度、2〜5行
- [ ] 結論がタイトルの言い換えになっていない
- [ ] 結論だけを順に読んで、飛躍・重複がない（あるなら報告に書いてある）
- [ ] 結論と本文・図が矛盾していない
- [ ] セクション名に番号を書いていない。オープニング・まとめ・付録は `numbered: false`

## 本文

- [ ] 1段目が見出し語（用語・対象・観点）、2段目がその中身になっている
- [ ] 用語を扱うスライドは定義が冒頭にある
- [ ] 1項目に1つの内容。「・」でつないだ3つ以上の名詞や、2文の項目が残っていない
- [ ] 例は `ex)` で始まる。手順は番号付き
- [ ] 1〜2行だけの薄い本文になっていない（入力に定義・例・理由があるのに引き上げていない、がない）
- [ ] 本文は12行程度まで、1行は全角25字程度まで
- [ ] 数値・固有名詞・定義・手順・比較の軸・URL・引用は画面に残っている

## 用語と文体

- [ ] 比喩がタイトル・結論・本文・図のラベルに残っていない
- [ ] 製品の機能は正式名で書いてあり、言い換えの概念名を作っていない
- [ ] 同じものを指す語が資料全体で1つに揃っている（計画の用語表どおり）
- [ ] 講演の段取りに触れる語（「後半で説明」「別資料」「今日は一言だけ」）が画面に無い
- [ ] 「勝者」「最適」「最強」などの評価語、無条件の礼賛がない

## 図解

- [ ] プロセス・分岐・対比・ループ・会話・階層・構成は図になっている
- [ ] 図が本文の箇条をそのまま箱に並べ直したものになっていない
- [ ] 図を置くために作った内容がない
- [ ] 対比は同じ部品を2つ並べている（`md-stack` に `Group` ×2）
- [ ] 会話のやりとりは `Sequence`、戻りのある流れは `Step` の `loop`
- [ ] `Branch` の `tag` が全部同じ語になっていない
- [ ] `Comparison` に `axes` があり、列見出しが具体名。`highlight` が勝敗の意味になっていない
- [ ] 同じ概念は同じ部品・同じ並びで描き、強調（`highlight`／`overlay`）だけが変わっている
- [ ] `EmphasisBox` は `::note::` に1スライド1つまで。結論の言い換えになっていない
- [ ] Step・Branch・Architecture・Sequence の外に矢印を足していない
- [ ] `Shot` の `todo` は入力が画面・実物に触れているスライドだけ

## デザイン

- [ ] `slides.md` に `<style>`、`style=`、色、文字サイズ、UnoCSS のクラスを書いていない
- [ ] レイアウトは同梱の7つだけ
- [ ] `figureWidth` は 33%〜55% の範囲
- [ ] headmatter が [components.md](components.md) の雛形どおり（`canvasWidth: 1920`、フォント、`colorSchema: light`）
- [ ] 画像を生成していない。差し込む画像は報告の一覧にある

## プレゼン全体

- [ ] 表紙がある。`##` が2つ以上なら区切りがある
- [ ] 目次・結びは入力にあるときだけ
- [ ] 進行だけのスライドは承認されたものだけ
- [ ] 発表者ノートは1〜3行で、つなぎ・要確認・画面から外した比喩だけ。想定時間を書いていない。表紙・区切りにノートが無い
- [ ] 持ち時間が分かっていれば、計画で枚数から見積もった
- [ ] `slide-plan.md` が承認した内容と一致している

## ビルド

- [ ] `npx slidev build` が通る
- [ ] `dist/` を消した
- [ ] 報告に、はみ出し・文字の重なり・結論欄の改行位置は実機で確認してほしいと書いた
