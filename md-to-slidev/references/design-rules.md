# デザイン規則

同梱の `style.css`・`layouts/`・`components/` が実装している規則。`slides.md` を書くときはこの規則の中で部品を選ぶ。規則を変えたいときは部品を直す。

## 基本コンセプト

白地・墨色の文字・細い罫線に、スチールブルー1色のアクセント。本文スライドは左に本文と図、右に結論欄を置く「仕様書」型。装飾ではなく「情報構造が明確で、図解によって理解できる」ことを優先する。

判断の優先順位: 内容の正確性 → メッセージの明確さ → 情報構造 → 図解 → レイアウト → タイポグラフィ → 色 → 装飾。

## 画面の構成

```
┌──────────────────────────────────────┬──────────────┐
│ タイトル（話題名）44px                  │ SECTION      │
│                                        │ 01 章の名前   │
│ ● 本文 1段目 26px          │  図        ├──────────────┤
│   2段目 22px（補足色）      │ （::figure::）│ CONCLUSION   │
│ ● 本文 1段目               │            │ 結論 30px     │
│                                        │ 1行12字程度   │
│ ┌ 強調（::note::）────────────────┐   │              │
│ └──────────────────────────────┘   ├──────────────┤
│                                        │ 05 / 38      │
└──────────────────────────────────────┴──────────────┘
```

- 結論欄の幅は 440px（`--md-side-width`）。結論は 30px なので、1行は全角12字程度
- SECTION は直前の `md-section` の章番号と題名が自動で入る
- 表紙は左寄せの大きなタイトル（132px）。区切りは CHAPTER 番号／総章数と、角に飾りの付いた枠の中に大きな番号と章題

## 色

| 用途 | 値 | 変数 |
|---|---|---|
| 背景 | `#FFFFFF` | `--md-bg` |
| 基本文字色 | `#1D1F20` | `--md-fg` |
| 補足文（本文2段目） | `#4A4F54` | `--md-sub` |
| ラベル・軸見出し | `#6A6F74` | `--md-muted` |
| 枠・罫 | `#B9BCC0` | `--md-line` |
| 表の行罫 | `#D3D5D8` | `--md-line-soft` |
| 矢印・接続線 | `#4A4F54` | `--md-line-strong` |
| 表の見出し行 | `#E4E6E9` | `--md-fill` |
| アクセント（スチールブルー） | `#5980A6` | `--md-accent-1` |
| 結論の文字 | `#2C4660` | `--md-accent-1-deep` |
| 強調の下地 | `#DDE6EF` | `--md-accent-1-tint` |

- アクセントは1色。本文の強調に赤・青などの派手な色を使わない。強調は配置 → サイズ → 太字 → 枠 → アクセントの順に検討する。色だけで重要度を表さない
- `highlight` は下地（tint）と太い枠で示す。比較で勝敗を色で示さない。「今話している列・工程」を示すためだけに使う

## フォントとタイポグラフィ

- 本文: Noto Sans JP（ウェイト 400/500/700）。英字ラベル（SECTION・CONCLUSION・CHAPTER・ページ数・図の見出し）: Barlow Condensed
- 薄い Light ウェイトを本文に使わない。装飾的なフォントも使わない

| 要素 | サイズ | 変数 |
|---|---|---|
| 表紙タイトル | 132px | `--md-size-cover` |
| セクションの番号／題名 | 200px／96px | `--md-size-section-num`／`--md-size-section` |
| タイトル | 44px | `--md-size-title` |
| 結論 | 30px | `--md-size-conclusion` |
| 本文 | 26px | `--md-size-body` |
| 本文2段目・補足・図のラベル | 22px | `--md-size-note`／`--md-size-label` |
| コード | 18px | `--md-size-code` |

- **22px 未満の文字は使わない**（コードブロックの 18px だけが例外）。`slides.md` で `text-sm` のようなクラスや `font-size` を書かない
- line-height 1.5。タイトル・結論・章題は `white-space: pre-line` なので、YAML の `|-` の改行がそのまま出る
- キャンバスは 1920×1080（`canvasWidth: 1920`）。上の px はこのキャンバス上の値。文字を大きくしたいときは `style.css` の変数を変える

## 余白

| 場所 | 値 |
|---|---|
| スライド外周 → 本文領域 | 56px（`--md-frame`） |
| 本文領域の内側 | 上下 64px・左右 72px |
| タイトル → 本文 | 40px |
| 本文の項目間 | 18px |
| 本文 → 図 | 48px |

内容が少ないスライドでは下が空く。それは情報の無さの表れであって、装飾やイラストで埋める理由にはならない。縦の間隔を1か所だけ広げたいときは `<Spacer />` を使う。

## 図解の基本スタイル

- 線: 1.25px。重要な線・強調だけ 2px
- 角丸: なし（0px）
- シャドウ・グラデーション: 使わない
- アイコン: 装飾目的で置かない。製品名の脇の `Logo` だけ
- 図の中の文字は 26px、`sub`・ラベルは 22px

## 画像

基本の UI・図形・矢印・ボックス・線・ラベルは、画像ではなく同梱の部品で作る。文字を含む図解を画像にしない。この Skill は画像を生成しない。

画面・生成物・公式の図のように、実物を見せると伝わるものは `Shot` で置き場所を作る。画像が無いうちは `todo` に入れる画像の説明を書き、点線の枠で表示する。利用者が `public/` に画像を置いて `src` を足す。

## 避けること

長い段落、22px 未満の文字（コードを除く）、過剰な余白、過剰なカード UI、太い枠線、シャドウ、グラデーション、原色、装飾目的のアイコン、スライドごとのデザイン変更、同じ概念を毎回別の図で表現、1スライドに複数の結論、入力にない事実の追加、比較での優劣の暗示、無条件の礼賛、`slides.md` での `style=` 直書き。

## デザインを差し替えるとき

`style.css` の変数（色・サイズ・余白）を変えれば、`slides.md` と部品の呼び出しはそのまま使える。レイアウトの構造を変えるなら `layouts/` を、図の見た目を変えるなら `components/` を、章番号の数え方を変えるなら `composables/chapters.ts` を直す。`slides.md` に手を入れる必要が出たら、部品の設計が漏れている印なので部品側に戻す。
